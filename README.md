# PustakMitra

PustakMitra is a full-stack book management system that allows users to efficiently manage book records. The system provides CRUD operations, real-time updates, and dynamic rendering for a seamless user experience.

---

## ✨ Features

- Developed a full-stack system with efficient **CRUD operations** to manage book records.
- Integrated **image upload** using Multer with optimized file handling and validation.
- Implemented **real-time updates** and **dynamic rendering** using EJS for an enhanced UI experience.

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js
- **Frontend**: EJS templates
- **Database**: MongoDB
- **File Upload**: Multer
- **Templating & Rendering**: EJS
